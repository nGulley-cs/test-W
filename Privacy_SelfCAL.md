# selfCal Privacy Policy

selfCal is a personal, single-user application. It is used only by its developer (Nate Gulley).

- **Data accessed:** My own Google Calendar data, via the Google Calendar API: my calendar list and my calendar events (read-only).
- **Purpose:** The data is displayed in my own self-hosted calendar service. It is not used for advertising, profiling, or any other purpose.
- **Storage:** Events and the OAuth refresh token are stored on my own private, self-hosted server. The token is encrypted at rest. Nothing is shared, sold, or disclosed to any third party.
- **Retention and deletion:** I can delete the stored data and revoke the app's access at any time from my Google Account's third-party access settings.
- **Google API Services User Data Policy:** selfCal's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
- **Contact:** https://github.com/nGulley-cs
